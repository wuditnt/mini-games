# ARCADE · 网页小游戏大厅

一个基于 Web 的轻量游戏大厅，内置《坦克大战》《打砖块》《星际弹幕》《贪吃蛇》《五子棋》，并预留了快速扩展新游戏的注册机制。支持桌面键鼠与手机触屏操作。

## 功能

- **游戏大厅**：游戏卡片展示，已上线 / 筹备中状态区分
- **坦克大战**：波次生存、道具掉落、护甲与基地防守、震屏与顿帧手感反馈
- **打砖块**：砖块多血、连击倍率、加宽挡板与分裂多球补给、关卡递进
- **星际弹幕**：弹幕闪避、擦弹充能、炸弹清屏、每五波 BOSS 战
- **贪吃蛇**：平滑移动、连击倍率、黄金果实、速度随长度提升
- **五子棋**：人机对战、形位评分 AI、悔棋、胜利连线高亮与胜负战绩
- **手机适配**：坦克大战双摇杆、打砖块拖动挡板、星际弹幕拖动战机、贪吃蛇滑动转向、五子棋点击落子，均支持暂停按钮、横屏提示与安全区适配
- **数据统计**：对局记录、总对局 / 最高分 / 平均分 / 最长生存、得分趋势图与记录表格
- **零外部资源**：画面与音效均由 Canvas 程序化绘制、WebAudio 实时合成

## 技术栈

| 分类 | 选型 |
| --- | --- |
| 构建 | Vite 5 |
| 框架 | React 19 + React Router 7 |
| UI 组件 | Ant Design 6（暗色主题） |
| 游戏渲染 | Canvas 2D（无第三方游戏引擎） |
| 音效 | WebAudio 合成 |
| 语言 | TypeScript |

## 快速开始

```bash
npm install
npm run dev      # 开发环境：http://localhost:6173
npm run build    # 类型检查 + 生产构建
npm run preview  # 生产预览：http://localhost:8020
```

开发与预览服务均监听所有网卡，同一局域网内手机可通过 `http://<本机IP>:6173` 访问。

## 操作方式

**坦克大战**

- 键盘鼠标：`WASD` / 方向键移动，鼠标瞄准，左键开火，`Esc` 暂停
- 触屏：左半屏拖动移动，右半屏拖动瞄准并自动开火

**打砖块**

- 键盘鼠标：`A` / `D` 或 `←` / `→` 移动挡板，鼠标移动跟随，空格或点击发球，`Esc` 暂停
- 触屏：拖动屏幕控制挡板，点击发球

**星际弹幕**

- 键盘鼠标：`WASD` / 方向键移动，`Shift` 低速精细移动，空格释放炸弹，`Esc` 暂停
- 触屏：拖动屏幕移动战机，点右上角 `✹` 释放炸弹

**贪吃蛇**

- 键盘鼠标：`WASD` / 方向键转向，`Esc` 暂停
- 触屏：在屏幕上滑动控制转向

**五子棋**

- 键盘鼠标：点击交叉点落子，`Z` 悔棋，`Esc` 暂停
- 触屏：点击交叉点落子，右上角按钮悔棋 / 暂停

**通用**

- 触屏设备右上角的 `❚❚` 按钮可随时暂停
- 游戏结束后可直接重开或返回大厅

## 数据统计

对局数据保存在浏览器本地（`localStorage`），不上传服务器：

- `arcade.runs`：对局记录，最多保留 200 条
- `arcade.sound`：音效开关偏好
- `tank.best` / `breakout.best` / `starfall.best` / `snake.best`：各游戏最高分
- `gomoku.record`：五子棋累计胜 / 负 / 平场次

统计页提供总对局、最高分、平均分、最长生存四项概览，以及得分趋势图和可排序的对局记录表格，并支持清空记录。如需多端同步或服务端统计，可替换 `src/data/runs.ts` 的读写实现。

## 新增游戏

1. 在 `src/games/<id>/index.ts` 中实现并导出 `mount(host, { onExit })`，返回 `{ destroy }`。
2. 在 `src/games/registry.ts` 中注册游戏信息（标题、描述、标签、封面 SVG、`loader` 懒加载）。
3. 大厅卡片会自动展示，点击后进入 `/play/<id>`，无需改动大厅代码。
